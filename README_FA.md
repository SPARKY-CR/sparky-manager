# vpn-panel — راهنما (فارسی)

پنل VPN چند هسته‌ای که از صفر ساخته شده است: **Xray-core + sing-box +
WireGuard** با یک رابط وب فارسی. برای کلاینت
[ZedSecure](https://github.com/EbiDevSharp/ZedSecure) ساخته شده است —
پنل همهٔ پروتکل‌هایی را که ZedSecure می‌تواند به آن‌ها وصل شود و به
سرور نیاز دارند، در دو قالب اشتراکی که ZedSecure می‌فهمد ارائه می‌دهد
(لینک‌های v2rayNG و JSON مربوط به sing-box)، به‌همراه QR کد.

پروژهٔ عمومی، با مجوز MIT. **کاملاً از صفر نوشته شده** — نه فورک و نه
کد کپی‌شده از 3X-UI، vpn-ui، مرزبان یا هیچ پنل دیگری.

> **وضعیت: فاز ۱ (MVP) ساخته شده است.** ۱۸۹ تست قبول می‌شوند؛ کانفیگ
> رندرشدهٔ Xray با Xray واقعی 26.11.9 (`xray run -test`) و کانفیگ
> sing-box با sing-box واقعی 1.14.4 (`sing-box check`) تایید شده‌اند.
> هنوز روی سرور واقعی نصب نشده — نصب تک‌خطی را اول روی یک سرور
> تازهٔ اوبونتو/دبیان آزمایش کنید.

## پنل چه می‌کند

- **ورود ثابت و قابل پیش‌بینی:** پنل روی پورت **۲۰۵۳**، مسیر `/`،
  نام کاربری `admin`. نه پورت و نه رمز تصادفی. نصب‌کننده در پایان یک
  جعبهٔ ورود بزرگ چاپ می‌کند و آن را در `/root/vpn-panel-login.txt`
  ذخیره می‌کند؛ با `sudo vpn-panel info` دوباره چاپ می‌شود.
- **بدون دامنه کار می‌کند.** با یک IP خالی سرور کافی است. جفت پیش‌فرض
  — **VLESS + Reality (TCP 443)** و **Hysteria2 (UDP 443)**، به‌همراه
  **WireGuard (UDP 51820)** — نه دامنه می‌خواهد نه گواهی. خود پنل،
  وقتی دامنه‌ای نیست، با گواهی self-signed بالا می‌آید (مرورگر هشدار
  می‌دهد؛ اثر انگشت گواهی در جعبهٔ ورود چاپ شده تا بررسی کنید). اگر
  بعداً در تنظیمات پنل دامنه وارد کنید، پروتکل‌های TLS و Let's Encrypt
  به‌عنوان یک گزینه در دسترس قرار می‌گیرند — هیچ‌وقت اجباری نیستند.
- **دو هسته کنار هم:** Xray-core برای VLESS، VMess، Trojan،
  Shadowsocks 2022 و Hysteria2؛ sing-box برای TUIC، AnyTLS، Naive و
  ShadowTLS. وایرگارد به‌صورت بومی (`wg0`) اجرا می‌شود.
- **اشتراک دو قالبه:** هر کاربر یک اشتراک توکن‌دار دارد، هم به قالب
  v2rayNG (لیست لینک base64) و هم JSON مربوط به sing-box، با تشخیص
  User-Agent یا `?format=`، به‌همراه صفحهٔ انسانی با QR کد.
- **کاربران:** سهمیهٔ ترافیک، تاریخ انقضا، فعال/غیرفعال، توکن اشتراک
  برای هر کاربر (قابل چرخش). آمار ترافیک از gRPC مربوط به Xray،
  `wg show` و شمارنده‌های nftables برای sing-box.

## نصب

فقط Ubuntu 22.04/24.04 یا Debian 12/13، با دسترسی root:

```bash
curl -Ls https://raw.githubusercontent.com/SPARKY-CR/Zed-panel/main/install.sh | sudo bash
```

> آدرس مخزن بالا **جای موقت** است تا وقتی جیمز مخزن
> `SPARKY-CR/Zed-panel` را بسازد. تا آن موقع، مخزن را clone کنید و
> از داخل آن `sudo bash install.sh` را اجرا کنید.

نصب بدون پرسش، با گزینه‌های مشخص:

```bash
curl -Ls https://raw.githubusercontent.com/SPARKY-CR/Zed-panel/main/install.sh | sudo bash -s -- --yes --reality-sni www.microsoft.com
```

نصب‌کننده قابل تکرار است (اجرای دوباره بی‌خطر است) و پیش از پایان،
خودش را بررسی می‌کند: پنل باید روی `/health` پاسخ `200` بدهد و
`xray` و `sing-box` باید فعال باشند، وگرنه ۲۰ خط آخر لاگ را چاپ
می‌کند و با خطا خارج می‌شود. آخرین نسخهٔ پایدار Xray-core و sing-box
را از انتشارهای رسمی گیت‌هاب می‌گیرد و هر وقت انتشار، digest مربوط
به SHA256 را داشته باشد، آن را بررسی می‌کند.

## ورود

`https://<IP-سرور>:<پورت>` را از جعبهٔ ورود باز کنید؛ نام کاربری `admin` و رمز عبور
هم در همان جعبه است. اگر دامنه دارید: `https://<domain>:<پورت>`.

```bash
sudo vpn-panel info      # چاپ دوبارهٔ جعبهٔ ورود
sudo vpn-panel status    # وضعیت سرویس‌ها
sudo vpn-panel restart   # راه‌اندازی دوبارهٔ پنل و هسته‌ها
sudo vpn-panel backup    # پشتیبان در /root/vpn-panel-backup-<date>.tar.gz
```

## پروتکل‌های پیش‌فرض (بدون نیاز به دامنه)

| پروتکل | پورت | هسته |
|---|---|---|
| VLESS + Reality | TCP 443 | Xray |
| Hysteria2 | UDP 443 | sing-box |
| Shadowsocks 2022 | TCP 8388 | Xray |
| WireGuard | UDP 51820 | بومی |

با دامنه و گواهی، TUIC (8443)، AnyTLS (8444)، Naive (8445) و
ShadowTLS (8446) هم در دسترس‌اند — ببینید
[docs/PORTS.md](docs/PORTS.md). چک‌لیست وارد کردن در ZedSecure در
[docs/ZEDSECURE.md](docs/ZEDSECURE.md) است.

## پرسش‌های متداول

**آیا دامنه لازم است؟**
نه. یک IP خالی سرور برای راه‌اندازی پیش‌فرض کافی است. دامنه فقط
پروتکل‌های مبتنی بر TLS و یک گواهی واقعی برای پنل اضافه می‌کند.

**مرورگر دربارهٔ گواهی هشدار می‌دهد — طبیعی است؟**
بله، وقتی دامنه‌ای نیست. پنل از گواهی self-signed استفاده می‌کند که
هنگام نصب ساخته شده است. پیش از ادامه، اثر انگشت SHA256 آن را با
اثر انگشت موجود در جعبهٔ ورود (`/root/vpn-panel-login.txt`) مقایسه
کنید.

**اطلاعات ورود را چطور دوباره چاپ کنم؟**
`sudo vpn-panel info`.

**حذف نصب چطور است؟**
`sudo bash install.sh --uninstall` — سرویس‌ها را متوقف می‌کند، یک
نسخهٔ پشتیبان در `/root/` نگه می‌دارد و `/opt/vpn-panel` را حذف
می‌کند.

**آیا پنل Psiphon، Tor یا تونل DNS اجرا می‌کند؟**
نه، به‌عمد. آن‌ها شبکه‌های سمت کلاینت یا شخص ثالث‌اند که ZedSecure
خودش دارد؛ یک پنل سرور چیزی برای اجرا کردن در آن‌ها ندارد.

## محدودیت‌های فاز ۱ (فهرست صادقانه)

- OpenVPN / OpenConnect و AmneziaWG فاز ۲ هستند، نه در MVP.
- IKEv2 اینجا بازنویسی نشده است — از
  [Ikev2-manager](https://github.com/SPARKY-CR/Ikev2-manager-) در کنار
  پنل استفاده کنید؛ پنل فقط وضعیت آن را نشان می‌دهد و به آن لینک
  می‌دهد.
- sing-box هیچ API آمار به‌ازای کاربر ندارد: برای اینباندهای اشتراکی
  sing-box، ترافیک «نامشخص» نمایش داده می‌شود، نه یک عدد ساختگی.
- فروشندگی / چند مدیر / صورتحساب و مدیریت چند سرور وجود ندارد.
- نصب‌کننده هنگام نصب، *آخرین* نسخهٔ پایدار هسته‌ها را می‌گیرد و در
  `/opt/vpn-panel/versions.env` ثبت می‌کند؛ به‌روزرسانی خودکار وجود
  ندارد.
